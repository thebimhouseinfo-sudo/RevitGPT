Use CadGPT's menu concept, not a second command execution engine. Accepted:
`rg/`, `rg/status`, `rg/tools [query]`, `rg/job [query]`,
`rg/dynamo [query]`, `rg/knowledge [query]`, `rg/help`.
`rg/status` checks native binding. Other commands only discover existing
Internal + User Registry or read knowledge snippets, with bounded output.
Commands route via `revitgpt_command(command=...)` or, for stale published
connector inventories, through EXISTING
`revitgpt_call(name="rg/tools", arguments={})` fallback.

A natural-language query still uses normal MCP tools; `rg/` is OPTIONAL.
A command is NOT a lease, does not run a Job or .dyn script, and cannot edit an
RVT. Direct Jobs, Dynamo engine adapter and mutating capabilities require
separate host QA, transaction/rollback and user consent in later phases.
